# Python interview lab

Each exercise is a directory with `problem.md`, `starter.py`, `solution.py`, and `test_solution.py`.

```bash
pytest python/beginner/<slug>/test_solution.py
```

That command runs the reference solution. Solve `starter.py` yourself, and only then compare.

Levels: beginner, intermediate, advanced. Topics include collections, comprehensions, generators, decorators, objects, errors, files, JSON, typing, tests, NumPy, and Pandas (duplicates, group aggregates, rolling statistics, transaction features, memory, chunks, datetime).

There are at least 150 exercises. `tests/test_content.py` counts them.
