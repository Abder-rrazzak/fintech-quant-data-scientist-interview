# Career roadmap

This page is a study map for a mid-level quantitative data scientist interview. It is not a biography and it does not invent employers.

## Foundations

Python, SQL, and statistics come first because the later modeling interviews assume them. Weeks 1–5 of `docs/12-week-plan.md` are that base.

## Financial decision modeling

Credit, fraud, and lifetime value are three different targets. Credit is a seasoned default. Fraud is a rare, delayed label on an authorization. Lifetime value is a revenue forecast with churn. Mixing the grains is a common fail.

## Scale and delivery

Spark, Snowflake, and AWS show up as design questions more often than as live coding. Be able to say when you would not use them, and be able to run the local stand-ins in this repository.

## How to present the work

Put the repository in a portfolio as a laboratory. In the README of each project, keep the business problem, the baseline, the validation window, and the limitation. Interviewers trust a limitation you named more than a metric you maximized.
